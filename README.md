# JS Basic - Bookstore & Reading Club 📚

A simple JavaScript project created to practice the basic concepts of JavaScript.

## About the Project

The project contains a simple Bookstore & Reading Club page where the user can:

- Enter their name.
- Choose a membership type.
- Select a book genre.
- Enter a book title.
- Receive a reservation message.

The project also includes several JavaScript exercises to practice the concepts learned during the course.

## Topics Practiced

- Variables
- Data Types
- `typeof`
- Arithmetic Operators
- Comparison Operators
- Logical Operators
- String Concatenation
- If / Else If / Else
- Switch Statements
- Prompt and Alert
- For Loops
- Functions
- String Methods
