# Bookstore & Reading Club 📚

A simple Bookstore and Reading Club project created to practice JavaScript fundamentals.

## About the Project

This project allows the user to:

- Enter their name.
- Select a membership type.
- Choose a book genre.
- Enter a book title to borrow.
- Receive a reservation message.
- View the entered information in the console.

The project also includes JavaScript exercises covering basic programming concepts.

## JavaScript Topics

The exercises include:

- Variables
- Data Types
- Operators
- Comparison Operators
- Logical Operators
- If / Else If / Else
- Switch Statements
- Prompt and Alert
- `typeof` Operator
- String Concatenation
- Loops
- Functions
- String Methods
